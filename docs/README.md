- [仓库结构](repository-layout.md)：源码、数据、文档和工具各在哪里。
- [架构](architecture.md)：数据、布局、渲染与存储的模块边界。
- [性能说明](performance.md)：复现基准测试，区分布局时间与交互性能。
- [贡献指南](../.github/CONTRIBUTING.md)：提交代码和公开示例前的检查。
- [发布检查](publish.md)：发布包、隐私与许可证核对。
