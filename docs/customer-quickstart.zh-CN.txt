Loregrid 客户使用说明
=====================

1. 双击 Loregrid.html 打开应用。
2. 右下角打开“树库”，选择要使用的树。
3. 如果需要添加其他树，在树库中选择“添加 JSON 树”。
4. 每棵树的分页、队列、完成记录和笔记彼此独立。
5. 左上角菜单可以导出树 JSON，或导出当前树的进度与笔记备份。
6. 更换电脑或浏览器前，请先导出树 JSON 和进度备份。

重要说明
--------

- 本版本没有服务器、账号和云同步。
- 树、进度、队列和笔记保存在当前浏览器的本地存储中。
- 清除浏览器数据、换浏览器或换浏览器配置文件，可能导致本地树库不可见。
- 交付包中的 trees 文件夹保存了本次交付的原始树 JSON，便于重新导入。
- 不要把包含私人笔记或进度的备份上传到公开仓库。
