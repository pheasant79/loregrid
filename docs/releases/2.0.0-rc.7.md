# Loregrid 2.0.0-rc.7

This revision corrects the learning-stage model and visual treatment:

- Stages are defined once at tree level and are reused by every page, combined page, and `All` view.
- Legacy page-scoped stage names are consolidated by order during migration; conflicting names become a neutral stage label with a warning.
- Cross-page proxies inherit the canonical node's stage.
- Stage completion is counted from canonical required nodes, so a partial page view cannot incorrectly mark a hidden tree-wide stage as complete.
- The canvas uses restrained YART-inspired stage regions: a faint vertical tint, a thin boundary, and a title at the top. No mainline or milestone badges were added to node headers.

This is a local release candidate. It is not customer acceptance or a public release.
