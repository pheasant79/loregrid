# Loregrid 2.0.0-rc.2

This release candidate refines the top navigation hierarchy and learning-queue workflow.

## Changes

- Research paths remain above the category selector in the top-left control area, beside the queue cards.
- Added a clear-queue action that appears only when the queue has items and asks for confirmation.
- Clearing the queue leaves completed-node records, private notes, and other progress preferences unchanged.

## Verification boundary

This is a versioned offline application build, not a claim of customer acceptance or complete YART parity. Review the actual customer tree and workflow before treating the handoff as accepted. Firefox and broader accessibility checks remain environment-dependent and must not be assumed to pass.
