# Loregrid 2.0.0-rc.3

本候选版本只处理有明显用户收益的 YART 风格视觉差异：

- 110%–130% 缩放时，节点卡片从 50 增至 66 个世界像素。
- 高缩放卡片显示通用的节点类型、简介／成果和完成状态。
- 焦点路径继续高亮，但默认不把无关节点压暗。
- 必需连线叠加 YART 自有 `EdgeLine.png` 渐变纹理；保留 Loregrid 的分页／完成颜色、箭头和长边路由。
- 新增高缩放卡片、焦点可见性和无相交检查；更新 Chromium 视觉基线。

这仍是候选版本，不代表完整 YART 复刻或客户签收。YART 的游戏专属研究花费、解锁物品、活动路径脉冲和精确坐标仍不属于 Loregrid。
