# Loregrid 2.0.0-rc.4

本候选版聚焦客户截图中最显眼的界面差异：

- 移除占据整行的独立品牌标题栏，将品牌、当前树名称、打开／菜单／语言操作收进左上控制区。
- 压缩顶部层级，让分页、分类、搜索与学习队列和研究画布共享同一个工作台区域。
- 节点采用统一的深蓝底和细边框，不再按分页整块染成不同颜色；前置锁定、可开始、已完成仍使用明确的状态差异。
- 节点标题放在左侧、状态符号收在右侧；普通依赖线统一为克制的灰蓝色，完成／当前路径再强调。
- 保留队列、分页、布局数据和完成记录，不增加演示节点，也不改布局算法。

验证结果：类型检查通过、36 项单元测试通过、Chromium 25/25 通过（含离线单文件打开与 10,000 节点用例）、演示树校验通过。10,000 节点流程中 1,000 节点分页的帧样本为本机一次运行中位 10ms／p95 12.1ms。

该版本是本地候选构建；测试结果不等同于客户验收。Firefox、全面无障碍审计和真实客户数据／流程验收未完成。交付时应同时提供 `LICENSE` 与 `THIRD_PARTY_NOTICES.md`。
