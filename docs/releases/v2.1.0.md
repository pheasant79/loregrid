# Loregrid v2.1.0

本次正式版集中完善更新流程、缩小后的图形辨识度和项目使用文档。

## 下载与使用

- **首次使用**：下载 `Loregrid-v2.1.0-offline.zip`，完整解压，双击 `index.html`。
- **已有用户**：先分别备份重要树的进度，下载 `Loregrid-v2.1.0-update.html`，关闭旧页面，将下载文件改名为 `index.html`，替换原位置的同名文件。
- **保留整个 `data/`**，不要用示例数据覆盖自己的树或进度。浏览器、配置或路径变化后，可能需要重新连接文件夹或恢复备份。

旧的 v2.0.0 没有检查更新按钮，需要手动下载本版本。从 v2.1.0 起，可点击左下角版本号或「⋯ → 检查更新」。

## 本次改进

- **应用内更新**：查询 GitHub 最新正式 Release、阅读说明并选择下载；可选每天启动时检查，默认关闭。失败时明确提示，不会把联网失败误报为最新版。
- **更新前备份**：更新窗口可下载当前树的进度备份；多棵树仍需分别备份。程序不会自动覆盖本机文件。
- **缩放与渲染**：改善缩小后的未完成节点对比、完成节点半透明填充、圆角与背景网格；保留阶段边框和完成状态的区别。
- **连线与布局**：改善低缩放连线的显示，保留按端点状态生成的完成渐变，补充布局与大树回归覆盖。布局仍是面向浏览器的 YART 算法适配，不是游戏引擎的逐像素复刻。
- **文档**：重做中英文首页，更新 155 节点总览与操作截图，补齐使用指南、FAQ、开发指南和 AI 建树提示词。

## 数据与兼容性

树内容继续使用 `loregrid/tree-v2`，进度使用独立的 `loregrid/progress-v2`；保留 V1 树与旧进度的读取兼容。

Chrome / Edge 支持授权数据文件夹；Firefox 使用手动 JSON 导入和进度备份。HTML 不会自动扫描旁边的文件夹。应用没有账号、云同步、遥测或自动计时研究。

更新检查仅访问 GitHub，不发送树、队列、笔记或进度；GitHub 会收到 IP 等常规网络信息。学习功能仍可离线使用。

## 发布前验证

- TypeScript 检查、95 项单元测试、两份示例数据校验及 139 个本地文档链接检查通过。
- Chromium / Firefox 完整回归及截图修正后的定向复测共覆盖 89 个通过用例；另 1 个 Firefox 文件夹授权用例因浏览器能力不支持而跳过。
- 两种浏览器均直接打开实际发行包 HTML 验证离线启动、版本号及更新失败后的继续使用。
- 1,000 / 5,000 / 10,000 节点合成布局测试完成；实际性能取决于设备与图形结构，不承诺任意大图持续 60 FPS。
- 两次构建的发布附件 SHA-256 一致；ZIP 仅含预定的 8 个文件，不含私人树、笔记或进度。

## English

This stable release adds an in-app update flow, improves low-zoom rendering, and rebuilds the project documentation.

**New installation:** extract `Loregrid-v2.1.0-offline.zip` completely and open `index.html`.

**Upgrade:** back up each important tree's progress. Download `Loregrid-v2.1.0-update.html`, close the old page, rename it to `index.html`, and replace the old app at the same location. Preserve all of `data/`. Browser/profile/path changes may require reconnecting the folder or restoring backups. The v2.0.0 package has no checker and must be upgraded manually.

The checker reads stable GitHub Releases, shows release notes and downloads, and offers an optional daily startup check that is off by default. No learning data is sent, and no local files are silently replaced. The dialog's backup covers only the current tree.

Rendering improvements cover low-zoom node contrast, translucent completed fills, rounded outlines, grid visibility, and connection rendering while preserving endpoint-based completion gradients. New regression coverage accompanies layout changes. The layout remains a browser adaptation of YART, not a pixel-identical game-engine port.

Chinese/English homepages now include actual overview/workflow screenshots, task-oriented user guides, FAQ, developer instructions, and corrected AI authoring prompts.

Tree/progress formats and V1 import compatibility are retained. Chrome / Edge support authorized folders; Firefox uses manual JSON import. No account, cloud sync, telemetry, or automatic timed research is provided. Offline learning remains available.

Validation included type checking, 95 unit tests, both example trees, 139 local documentation links, and 89 passing browser cases across the full run and focused screenshot reruns. One Firefox folder-access case was skipped because the API is unsupported. Actual packaged HTML was opened directly in both browsers. Synthetic layouts covered 1k/5k/10k nodes; performance depends on the device and graph. Two builds produced identical asset hashes, and the ZIP contains only eight allowlisted files.
