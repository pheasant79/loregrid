# Loregrid 2.0.0-rc.9

This revision adds a browser-local tree library:

- Add multiple V1/V2 JSON trees in one file-selection operation.
- Open previously added trees from a compact lower-right selector.
- Search tree names and filenames in a height-limited, scrollable list; collapse it when unused.
- Restore each entry's queue, completion, private notes, page presets and last page independently.
- Keep separate local progress even when imported files share the same tree ID.
- Copy matching legacy progress into the first eligible entry while preserving original records.
- Store catalog metadata separately from tree content so startup does not read all graphs.
- Retain direct-file offline operation, import validation and safe text rendering.

Trees are explicitly added by the user, not discovered by silently scanning disk folders. The library stores copies; changing the source JSON does not update an existing entry. Keep the source files and export each tree's progress backup. Browser data clearing or a different browser/origin may make the local library unavailable.

This is a local release candidate, not a public release or a claim of customer acceptance.
