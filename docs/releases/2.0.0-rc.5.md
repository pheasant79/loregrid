# Loregrid 2.0.0-rc.5

This revision addresses the customer-facing YET parity issues that were most visible in the workbench:

- The top-left now has `All` plus one compact page selector. Paths and categories are represented by the selector value instead of a duplicated path-button row.
- In trees with multiple paths, the page selector labels identify both the path and page; path labels are not hidden just because page titles happen to be unique.
- Nodes use one browser-stable neutral card skin across pages. Completion remains the only full-card state color; ready uses a small amber status marker.
- Locked and ready cards also share the same neutral background and full opacity; status is conveyed by the small icon instead of dimming the whole card.
- Removed browser-native node-name tooltips and Firefox-sensitive CSS mask borders from the primary node card.
- The fit-view control uses an inline SVG so it does not depend on each browser's font glyph.
- The detail panel puts queue and completion actions immediately after the summary, in a compact two-column action block.
- “Unlocks” now explains whether other required prerequisites are still missing.
- The queue clear action is fixed at the queue header's right side and uses a clear red destructive treatment.
- Stage hints are shown as subtle canvas bands only when real numeric stage data exists; the app does not invent discipline-specific eras.
