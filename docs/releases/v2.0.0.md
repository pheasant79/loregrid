# Loregrid v2.0.0

Offline release / 离线正式版。

This release promotes the rc.9 application to v2.0.0 with consistent version labels
in the app, download package, and release notes. It introduces no new graph, layout,
or completion-state behavior compared with rc.9.

本次将 rc.9 发布为 v2.0.0 正式版，统一程序、下载包和发布说明中的版本。
相比 rc.9，没有改动图模型、布局算法或完成状态逻辑。

## 下载与启动 / Download and open

Download **Loregrid-v2.0.0-offline.zip** from this release's Assets.
Extract the entire archive and double-click **index.html**. No installation,
Node.js, pnpm, Vite, server, or account is required.

请下载 Assets 中的离线包，完整解压后双击 `index.html`。
`Source code` 是开发源码包；普通使用推荐下载名称带 `offline` 的附件。

## Included

- Paged learning maps and one All overview per tree.
- Shared learning stages, dependency layout, search, and cross-page navigation.
- Learning queues, manual completion, notes, and separate progress backups.
- Loregrid V2 and legacy Learning Tech Tree V1 import.
- A fictional demo and the 155-node computer-science sample under `data/trees/`.
- A data/progress folder, bilingual startup instructions, and MIT/third-party notices.

## 数据与浏览器 / Data and browsers

- HTML starts with one bundled fictional demo; it does not scan neighboring folders.
- Chrome / Edge: upper-left **⋯ → Choose data folder**, select **data**, and grant
  access. Reload data after changing tree JSON; reconnect if permission expires.
- Firefox: use manual JSON import and progress export/restore. Folder access is
  not available through the same browser API.
- Trees are read-only definitions. Completion, queue, and notes are separate.
  Browser storage is a cache, not a substitute for backups.
- There is no cloud sync, account, backend, or automatic timed research.

## Scope

Loregrid adapts general YART layout and interface ideas for a standalone learning
viewer. It is not a RimWorld mod or a pixel-identical YART implementation.
See the repository's source map and third-party notices for attribution.

Keep the original tree files and back up progress before moving the HTML, changing
browsers, or clearing browser data. A new HTML path may use different browser storage.
Do not overwrite important progress files without making a backup first.
