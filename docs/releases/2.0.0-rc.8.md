# Loregrid 2.0.0-rc.8

This revision aligns stage identity and visual feedback across the complete tree:

- Stage definitions are shared by every page, combined page, and All view.
- Stage regions use restrained vertical tints and boundaries; stage completion does not recolor the whole region.
- Node borders and completed-node fills use their assigned stage color, including across Chromium and Firefox.
- Required edges use a muted, continuous stage-aware transition regardless of progress; completion no longer changes their color to generic green.
- Selecting All hides the page selector, and selecting All again returns to the previous page.
- Page choices are grouped by path without repeating path names in each option.
- The board no longer duplicates the page title and node count in its upper-left corner.
- High-zoom node titles center; medium-zoom titles remain left-aligned.
- The top learning queue has a persistent, keyboard-operable horizontal scrollbar.
- The layout no longer treats stage order as a mandatory rank barrier.

This is a local release candidate. It is not customer acceptance or a public release.
