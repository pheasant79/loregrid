# Loregrid 2.0.0-rc.1

## What this version is

A versioned, offline customer-use release candidate for paged learning trees. The footer in the app and the standalone build identify this version. It supports V1/V2 tree input, independent page and All layouts, cross-page prerequisites, search, a learning queue, favorites, combined pages, completion, notes, and separate progress backups.

The normal build includes a fictional starter tree and accepts users' own V1/V2 files. Customer-specific content is optional for this general application. To embed an agreed tree directly, build with:

```powershell
pnpm build:customer -- local-data\customer-tree.json
```

The command validates V1/V2 input, embeds it in the offline HTML, writes `dist/index.html`, and assembles `dist/customer-delivery/` with the versioned HTML, `LICENSE`, and `THIRD_PARTY_NOTICES.md`. The HTML contains the tree data. Keep customer input and generated customer builds out of public Git history.

## Verification

- TypeScript check and Vitest suite.
- Chromium browser tests, including local-file offline use and a 10,000-node fixture.
- Tree import validation and customer-build input validation.
- Firefox is configured but not verified in the current Windows environment; broader accessibility/Safari review is not certified.
