# Loregrid 2.0.0-rc.6

This revision adds explicit, data-driven learning stages:

- V2 trees may define named stages, optionally scoped to a page and/or research path.
- Existing V1 `stages` names are preserved when loaded and migrated.
- Nodes keep stage order as a layout hint; the layout adds stage-order constraints only when they do not conflict with required dependencies.
- Canvas stage regions show the page-specific phase name, required-node completion count and a restrained progress rail. Finished phases get distinct restrained stage-region accents; completed node cards keep their existing green state and are otherwise unchanged.
- Optional nodes do not block stage completion. Stages with no required nodes show no completion percentage.
- The fictional demo now demonstrates distinct stage names across its pages. No customer/discipline-specific stage labels are invented.
- No mainline or milestone badges were added.

The stage data contract is described in `docs/data-format.md`.

This is a local release candidate, not customer acceptance or a public release. The handoff artifact is `dist/index.html`; the customer-data build remains opt-in via `pnpm build:customer`.
