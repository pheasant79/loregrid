# Repository layout

The repository separates application source, example data, and generated output:

- **Source files** are the application and materials maintained in Git.
- **`dist/`** is generated by `pnpm build` and ignored by Git.
- **Tree definitions** are JSON source files stored in `data/trees/`; progress is kept
  separately in browser storage and optional files in `data/progress/`.

## Folders

```text
loregrid/
├── src/                 TypeScript application, graph algorithms, renderer and worker
├── data/
│   ├── trees/           Tracked examples plus ignored user/AI-authored trees
│   └── progress/        Ignored per-tree progress JSON
├── docs/                User guides, format references, architecture, templates and notices
├── .github/             GitHub contribution guidance
├── schema/              JSON schema for tree format
├── tests/               Unit tests, browser workflows and visual fixtures
├── scripts/             Validation, migration and benchmark commands
├── prompts/             Optional prompts for authoring tree JSON
├── README.md            Project overview and first-run instructions
├── index.html           Vite development entry
├── package.json         Commands and development dependencies
├── pnpm-lock.yaml       Reproducible dependency versions
├── pnpm-workspace.yaml  pnpm workspace settings
├── tsconfig.json        TypeScript compiler settings
├── vite.config.ts       Development and single-file build settings
├── playwright.config.ts Browser test settings
├── .gitignore           Excludes generated output and personal data
├── AGENTS.md            Repository-specific coding and safety rules
└── LICENSE              Loregrid and preserved upstream MIT terms
```

`data/trees/` is the single location for tree definition JSON. Included examples are
tracked; personal tree files are ignored. Progress JSON belongs in `data/progress/` and
is ignored. The authoring template and compatibility fixture live outside these runtime
data folders. The root build and tooling configuration stays at the repository root
because pnpm, TypeScript, Vite, and Playwright discover it there; user guides and legal
references are grouped under `docs/`.

Third-party license notices are in `docs/legal/THIRD_PARTY_NOTICES.md`.

## Start and build

Run the app during development:

```powershell
pnpm install
pnpm dev
```

Build the standalone offline app:

```powershell
pnpm build
```

The generated entry point is `dist/index.html`. It contains the bundled application;
the TypeScript algorithms remain readable in `src/`.

## Tree and progress storage

On supported browsers, connect `data/` once. Startup and explicit refresh read tree JSON
from `data/trees/`; Loregrid never edits those files. Progress is saved separately to
`data/progress/` and cached in browser storage. Other browsers can import JSON manually.
See [the local data folder guide](data-folder.md).

For all guides, see the [documentation index](README.md).
