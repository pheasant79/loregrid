# 公开树库与本地树库

右下角的树库统一显示三类内容：内置树、本地导入树、公开目录中的树。它们各自保留分页、总览、队列、完成记录和笔记，不增加跨树总览。

- 启动时先读取浏览器中的本地树、缓存目录与已下载公开树，并恢复上次打开的树。
- 联网网页版随后更新公开目录，只读取标题、文件名和下载地址，不下载所有节点。
- 点击尚未缓存的公开树时才下载 JSON；应用校验格式、关系、安全链接和树 ID，再打开并保存离线副本。
- 再次打开公开树会尝试读取最新 JSON；网络失败时使用已有缓存。更新沿用该公开树的进度键，不覆盖本地导入文件的记录。
- 公开目录删除某项后，已下载的副本仍保留在树库中。
- 无法持久保存时，树仍可在当前会话打开，并提示导出备份。

## 添加可公开的树

源码中的 `public/tree-catalog.json` 是公开目录，默认没有条目。公开树 JSON 可以放到 `public/trees/`，例如：

```text
public/
├── tree-catalog.json
└── trees/
    └── history.json
```

目录内容：

```json
{
  "format": "loregrid/public-tree-catalog-v1",
  "trees": [
    {
      "id": "history",
      "title": "历史学习",
      "url": "./trees/history.json",
      "fileName": "history.json"
    }
  ]
}
```

`id` 必须唯一且与树 JSON 的 `id` 一致。`title` 是目录显示名；`fileName` 可省略。`url` 相对于目录本身解析，也可使用 HTTP(S) 完整地址。跨站来源需要允许浏览器跨域读取。目录结构另见 `schema/public-tree-catalog.schema.json`。

运行 `pnpm dev` 时可以直接验证。构建后，`public/` 中的文件会复制到 `dist/`；网站需部署 HTML、目录和公开 JSON。只改目录与 JSON 不需要修改 UI 代码。

如果目录托管在别处，可以在运行开发服务器或构建前设置 `LOREGRID_PUBLIC_TREE_CATALOG_URL` 为目录的完整 HTTP(S) 地址。此设置不包含私人文件的位置或身份凭据。

## 离线与隐私

双击 `dist/index.html` 的 `file:` 模式不会联网读取公开目录。它保留内置树、当前浏览器存储中可访问的本地树与公开树缓存。网页版和离线文件的浏览器存储可能互不相通，不能承诺从网站缓存的内容自动出现在离线文件中；重要树请导出 JSON，并分别备份进度。

这是只下载、不上传的功能：不会扫描硬盘，不会同步笔记、队列或完成记录。请求公开目录和公开树时不主动发送站点凭据和来源页地址，但托管方仍可看到正常网络请求信息。个人或客户树通过应用导入；不要放进 `public/trees/`，也不要提交到 Git。`local-data/` 只是开发时的临时输入目录，并非应用的运行时数据目录。

目录会随应用启动更新；节点布局仍在打开树后由 Worker 计算。超过一万节点不会仅因数量被拒绝，大文件沿用打开确认提示。
