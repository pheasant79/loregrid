# Tree JSON files

This is the single folder for tree definitions used by the local data-folder workflow.
The fictional examples are tracked by Git. Personal or AI-generated trees belong here
too, but are ignored by Git so they are not accidentally published.

After choosing the `data/` folder in Loregrid, the app reads JSON files in `trees/` when
it starts or when you select **Reload data folder**. Tree definitions are read-only in
the app; edit them with your authoring tool and reload Loregrid to see updates.

Use the template in [`../../docs/templates/minimal-template-v2.json`](../../docs/templates/minimal-template-v2.json)
when starting a new tree.
