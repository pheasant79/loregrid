# 创建 Loregrid 学习树：可复制提示词

复制下面内容，填入方括号中的需求。完整流程见 [创建学习树指南](../docs/create-with-codex.md)。

```text
请在当前 Loregrid 仓库中创建或更新学习树。
先完整读取 AGENTS.md、docs/data-format.md、docs/customization.md，
参考 docs/templates/minimal-template-v2.json，不要修改查看器程序。

主题与范围：[填写]
已有基础：[填写]
可检查的学习成果：[填写]
分页建议：[填写或请你提出]
语言与深度：[填写]
其他限制：[填写]
内容是否准备公开：[是 / 否；公开前仍需人工审查]

只输出 data/trees/<稳定ID>.json，格式为 loregrid/tree-v2。
不生成额外 HTML，不修改进度，不构建、不提交、不推送或发布。
树定义是作者维护的固定学习内容，浏览器只读取；
完成、队列和私人笔记属于独立进度，不写入树 JSON。

每个节点属于一个主分页，使用稳定 ID，给出明确的学习介绍、
适用范围与可观察成果；可附警告、标签和核对过的资源。
更新现有树时保留树 ID 与已有节点 ID，不因改标题而更换 ID。

required 表示真正必需的前置，多个前置为 AND，禁止循环。
recommended 是有方向但不锁定的推荐；related 是无方向关联。
允许多个根、叶与里程碑，不为了连通而编造依赖。
总览包含当前树全部分页。可选阶段必须全树共用同一套定义，
不能每页各自命名阶段；没有合理划分时不填。
位置与连线由程序计算，不写 x/y；分组与排序只作为可选提示。

专业事实请核对可靠的一手来源，不编造引用；区分已核实事实与教学设计。
不要默认统一学制、机构要求、论文数量或学习时长。
不包含身份、凭证、私人笔记、进度、未公开材料或本机路径。
所有树仍放在 data/trees/，不要另建公开/私人两套树目录。

若当前环境能运行仓库工具，请校验生成的文件：
pnpm validate -- data/trees/<稳定ID>.json
分别说明结构校验、内容核查和浏览器查看的实际结果；
没有做过的检查必须明确说明。
```
